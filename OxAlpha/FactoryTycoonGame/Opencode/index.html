📘 How to run a factory

Goal

Build a self-running production line: extract ore → smelt ingots → craft goods → sell. Reinvest profits into faster machines, better recipes and new land.

Controls

W A S D walk
Mouse look (click world to lock)
Shift sprint
Space jump
1–6 pick machine to build
R / Wheel rotate blueprint
LMB place / demolish
X toggle demolish mode
B shop (upgrades & land)
H this help
M mute · F quick-save · Esc menu

The machines

⛏ Extractor — must sit on an ore deposit, auto-mines forever.
➡ Conveyor — carries items; arrows show flow direction.
🔥 Smelter — ore → ingot (3× sale value).
⚙️ Assembler — crafts Gears (2 iron) and Circuits (iron + copper).
📦 Storage — 16-slot buffer that smooths bottlenecks.
💰 Market — buys anything you feed it, instantly.
💡 Watch the status lights: green = working, yellow = output jammed, red = starved. A red extractor next to a slow smelter means it's time to upgrade or add machines.
